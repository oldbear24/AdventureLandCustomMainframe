Co postavy dělají a jak je řídit

Nastavení, která CODE běžící postavy nabízí: hlavní cíl farmení, přepínače modulů, výpravy a vlastní hodnoty. Změna se projeví hned. Se zaškrtnutým Pamatovat panel hodnotu uloží a nastaví ji znovu po každém připojení postavy (úložiště CODE začíná po novém připojení prázdné).

Jak do CODE přidat vlastní nastavení a hlášení činnosti

Panel čte globální proměnné CODE postavy. Stačí do CODE přidat například:

window.mainframe_controls = [
  { key: "mode", label: "Režim", type: "select", options: ["farm", "home"],
    get: () => mode, set: value => { mode = value; } },
  { key: "minPotions", label: "Minimum lektvarů", type: "number", min: 0, max: 9999,
    get: () => minPotions, set: value => { minPotions = value; } },
  { key: "loot", label: "Sbírat kořist", type: "boolean",
    get: () => loot, set: value => { loot = value; }, status: () => "truhel: " + Object.keys(get_chests()).length },
];
window.mainframe_activity = () => ({ current: "Boj: goo", next: "Doplnit lektvary", mode: "work",
  events: [{ at: Date.now(), text: "Zabit goo", status: "confirmed" }] });

Typy: boolean, number, text, select, item, monster a target (hodnota {target, goal}). set může vrátit false, když hodnotu odmítne. Volitelně group, help a status. Bez úprav panel rozpozná adventure_primary (cíl farmení) a adventure_team (moduly, výpravy, plán a události). Pole Příkaz volá handle_command(název, argumenty) stejně jako příkaz napsaný v herním chatu, do chatu ale nic neposílá.
