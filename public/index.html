    Adventure Land účet

    Přihlášení proběhne přes Adventure Land. Heslo se neukládá; získaná relace je na serveru uložena šifrovaně.

    Steam účet nebo přihlášení pomocí cookie

    Použij cookie z již přihlášeného herního klientu. Při spuštění postavy aplikace ověří platnost relace.

    API token — Connect an AI / MCP

    Token načte seznam postav a herní CODE sloty. Pro běh postav a převody zůstává potřeba herní přihlášení. Token se ukládá šifrovaně.

    Upozornění — Discord / Telegram

    Poslat z postavy

    Příjemce musí být poblíž na stejné mapě a serveru. Zlato podléhá herním pravidlům včetně případného poplatku.

    Uložené hodnoty CODE

    Hodnoty, které CODE uložil funkcí set(name, value) a čte přes get(name). Čtou se živě z prohlížeče běžící postavy. Úprava nebo smazání se projeví hned; běžící CODE ale může hodnotu svým dalším set() přepsat.

    Změnit server postav

    Postavy

    Běžící postavy se zastaví, přesunou a znovu spustí. Autostart zůstane zachován.

    Přidat postavu

    Nečinnost znamená žádný pohyb, útok, skill, XP ani změnu zlata. Hodnota 0 kontrolu vypne (např. pro merchanta, který stojí ve městě).

    Před spuštěním odpoj postavu z ostatních klientů. Po uložení ji spustíš tlačítkem Start.
